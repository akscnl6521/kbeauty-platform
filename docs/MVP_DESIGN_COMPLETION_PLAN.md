# MVP_DESIGN_COMPLETION_PLAN.md — 한국 MVP 디자인 완성 로드맵

최종 갱신: 2026-07-18  
범위: **한국 MVP 화면** · 전면 재디자인 금지 · 연속 자동 실행 가능한 순서만 확정

## 디자인 방향

- 럭셔리 K-뷰티 · 글로벌 · 충분한 여백
- 첫 화면에 상품 과다 노출 금지 · 카드 남용 금지 · 저가 쇼핑몰 느낌 금지
- 모바일 우선 · 접근성 (`skip-to-content` · touch-target · sticky header offset)
- 공통: `PublicChrome` · `SiteHeader` · `globals.css` 토큰 (`--site-header-height`, `--site-content-max`)

---

## 실행 순서 (자동 연속 수행용)

1. 홈 `/`  
2. 피부 분석 `/analyze`  
3. 메이크업 문진 `/quiz/*` (mascara → base → lip)  
4. 헤어 문진 `/quiz/hair`  
5. 결과 `/results`  
6. 로그인·회원가입 `/login` `/signup`  
7. 마이 `/my` · 루틴 `/my/routine` · 피부관리 `/my/progress`  
8. 체크인 `/my/check-ins`  
9. 관리자 최소 polish `/admin` (공개 UX 후순위)  
10. **신규** 공개 제품 상세 → 비교 (현재 라우트 없음 · Phase B 후반)

한 화면 단위: 수정 → `check:responsive` → 필요 시 해당 라우트 스모크 → 문서 체크 → 다음 화면.
