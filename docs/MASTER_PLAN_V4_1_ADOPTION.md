# K-Beauty Match Master Plan v4.1 채택 기록

최종 갱신: 2026-07-19

## 공식 기준

K-Beauty Match의 최상위 기준 문서는 사용자가 2026-07-18 확정한 **K-Beauty Match Master Plan v4.1 — 글로벌 피부·뷰티 맞춤 관리 플랫폼 최종 통합 명령 프롬프트**다.

기존 `MASTER_PLAN.md` v3.1보다 v4.1을 우선한다. 이후 기획, UX·UI, 데이터, 추천, 제품 자동수집, 영상, 지속관리, 증상 기반 피부과 추천, 제휴·광고 분리, 자동 갱신과 운영 자동화는 v4.1을 기준으로 수행한다.

## v4.1 핵심 추가·확정 범위

1. 인기 제품 후보 탐색과 공식 출처 기반 제품·전성분 자동수집
2. Staging 후보 등록, 품질 게이트와 통합 예외 검수
3. 제품별 도포량·사용 순서·바르는 영상과 미디어 권리 관리
4. 3일·7일·15일·30일 피부 경과 관리와 재방문 대시보드
5. 증상·심각도·부위·근거에 따른 피부과 추천
6. Organic 추천과 화장품 제휴·제휴 피부과·스폰서·광고의 명확한 분리
7. 가격·재고·전성분·영상·병원·제휴 정보의 주기적 재검증
8. 핵심 변경의 버전 관리, 사람 검수, 감사 기록과 rollback
9. main·Production·Production DB 등 고위험 작업의 명시 승인 유지

## 현재 구현 완료 범위

- 고민별 증상 관찰 입력과 위험 신호 분기
- 긴급·전문가 우선 단계의 제품 노출 제한
- 분석 결과 자동 저장과 Day 3·7·15·30 체크인
- 악화 감지와 전문가 상담 안내
- `/my` 현재 상태·다음 체크인·상담 필요도 요약
- 한국 화장품 정보 갱신 주기 정책
- 매일 갱신 대상 계획 생성
- 공식 출처 수집 결과의 신규·갱신·변경 없음·수동 검수·거부 판정
- 판정 결과를 Staging 동기화 작업 계획으로 변환

## 제품 자동화 안전 원칙

- 공식 출처가 확인되지 않은 정보는 생성하지 않는다.
- 전성분·가격·재고·이미지가 없으면 누락 상태로 유지한다.
- placeholder와 발견용 가상 후보는 제품으로 공개하지 않는다.
- 자동 수집 결과는 Staging 후보 또는 수동 검수 대상으로만 처리한다.
- 변경이 없는 제품은 DB 쓰기를 생략한다.
- Production 공개·검증 상태 자동 승격은 금지한다.

## 구현 순서

1. 현재 상태 안정화
2. 플랫폼 핵심 사용자 여정
3. 제품 데이터 자동화
4. 사용 영상과 루틴
5. 리텐션
6. 증상 기반 피부과
7. 수익화
8. 자동 갱신·운영 자동화
9. 통합 검증과 출시

새 아이디어는 현재 작업을 즉시 바꾸지 않고 v4.1의 모듈과 ROADMAP 단계에 배치한 뒤 순서대로 구현한다.

## 운영 제한

이 채택 기록은 작업 브랜치에만 반영한다. 이 변경으로 main 병합, Production 배포, Production DB write, Production 환경변수 변경은 수행하지 않는다.

전체 업로드 원문 프롬프트는 저장소에 복사하지 않았으며, 이 문서는 구현에 반영된 채택 범위와 운영 경계를 기록한다.
