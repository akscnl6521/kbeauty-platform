# K-Beauty Match Master Plan v4.1 채택 기록

최종 갱신: 2026-07-18

## 공식 기준

K-Beauty Match의 최상위 기준 문서는 사용자가 2026-07-18 확정한 **K-Beauty Match Master Plan v4.1 — 글로벌 피부·뷰티 맞춤 관리 플랫폼 최종 통합 명령 프롬프트**다.

기존 `MASTER_PLAN.md` v3.1보다 v4.1을 우선한다. 이후 기획, UX·UI, 데이터, 추천, 제품 자동수집, 영상, 지속관리, 증상 기반 피부과 추천, 제휴·광고 분리, 자동 갱신과 운영 자동화는 v4.1을 기준으로 수행한다.

## v4.1 핵심 추가·확정 범위

1. 인기 제품 후보 탐색과 공식 출처 기반 제품·전성분 자동수집
2. Staging 후보 등록, 품질 게이트와 통합 예외 검수
3. 제품별 도포량·사용 순서·바르는 영상과 미디어 권리 관리
4. 3일·7일·15일·30일 피부 경과 관리와 재방문 대시보드
5. 증상·심각도·부위·근거에 따른 피부과 추천
6. Organic 추천과 화장품 제휴·제휴 피부과·스폰서·광고의 명확한 분리
7. 가격·재고·전성분·영상·병원·제휴 정보의 주기적 재검증
8. 핵심 변경의 버전 관리, 사람 검수, 감사 기록과 rollback
9. main·Production·Production DB 등 고위험 작업의 명시 승인 유지

## 구현 순서

1. 현재 상태 안정화
2. 플랫폼 핵심 사용자 여정
3. 제품 데이터 자동화
4. 사용 영상과 루틴
5. 리텐션
6. 증상 기반 피부과
7. 수익화
8. 자동 갱신·운영 자동화
9. 통합 검증과 출시

새 아이디어는 현재 작업을 즉시 바꾸지 않고 v4.1의 모듈과 ROADMAP 단계에 배치한 뒤 순서대로 구현한다.

## 운영 제한

이 채택 기록은 문서 작업 브랜치에만 반영한다. 이 변경으로 main 병합, Production 배포, Production DB write, Production 환경변수 변경은 수행하지 않는다.
