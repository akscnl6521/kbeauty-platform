# 126 — Routine Adjustment Policy

최종 갱신: 2026-07-13

## 제안 예시

- 초기 자극 높음 → 사용 빈도 낮추기 제안
- 건조 악화 → 보습 단계 강화 제안
- 유분 증가 → 무거운 제형 재검토
- 루틴 과다 → 단계 단순화
- 중복/충돌 → 하나 중단 제안
- 효과 불명확 → 2~4주 관찰 안내
- 심각한 반응 → 중단·전문가 상담 안내

## 규칙

- `requiresUserConfirm: true` 필수
- 적용 버튼 후에만 새 루틴 버전 저장
- 자동 덮어쓰기 · 의약품 지시 · 진단 · 치료 계획 확정 금지
