최종 갱신: 2026-07-13  
상위 문서: `MASTER_PLAN.md`, `PROJECT_RULE.md`

---

## 1. 목적

K-Beauty Match는 브랜드별 제품 DB를 무작정 대량 구축하지 않는다.  
실제 판매·전성분·논문·안전·관리자 검증을 통과한 제품만 등록·추천한다.

공식 이름: **Search-to-Verified-Product Pipeline**

---

## 2. 파이프라인 단계

1. 사용자 피부 고민 또는 제품군 검색  
2. 실제 판매 제품 후보 발견  
3. 판매 페이지 확인  
4. 가격과 구매 버튼 확인  
5. 품절 여부 확인  
6. 배송 국가 확인  
7. 공식 제품명·브랜드·용량 확인  
8. 전체 전성분 확인  
9. 성분 표준화  
10. 논문·피부과학 근거 검토  
11. 자극·알레르기·회피 성분 검토  
12. 관리자 검증  
13. Supabase 등록  
14. 추천 사용  

검색 결과에 노출된다는 이유만으로 재고가 있다고 판단하지 않는다.

---

## 3. 판매 가능 판단 조건

모두 충족해야 판매 검증 통과로 본다.

- 실제 상품 상세 페이지 존재  
- HTTPS URL  
- 공식 또는 신뢰 판매처  
- 가격 표시  
- 구매 버튼 존재  
- 품절 상태 아님  
- 해당 배송 국가에서 구매 가능  
- 최근 확인일 존재  

판매 상태 확인 전에는 핵심 추천에 포함하지 않는다.

---

## 4. 제품 상태

| 상태 | 의미 |
|------|------|
| `discovered` | 검색으로 후보만 발견 |
| `sale_checked` | 판매·가격·재고·배송 확인 |
| `ingredients_checked` | 전체 전성분 확인·표준화 |
| `evidence_checked` | 성분별 논문·근거 검토 |
| `safety_checked` | 자극·알레르기·회피 검토 |
| `verified` | 관리자 검증 완료 |
| `published` | 추천에 사용 가능 |

**`published`가 아닌 제품은 핵심 추천에 사용하지 않는다.**

---

## 5. 논문 근거 저장 항목 (IngredientEvidence)

- PMID 또는 DOI  
- 연구 유형  
- 연구 대상  
- 성분 농도  
- 제형  
- 사용 기간  
- 주요 결과  
- 근거 수준  
- 이해상충  
- 검토일  
- 검토 상태  

의약품 연구와 화장품 연구를 구분한다.  
성분 하나 논문만으로 제품 전체 효과를 단정하지 않는다.

---

## 6. 추천 판단 근거 순서

1. 사용자 피부 상태  
2. 전체 전성분  
3. 성분별 논문 근거  
4. 제형·농도·사용 부위  
5. 자극 가능 성분  
6. 알레르기 및 회피 성분  
7. 실제 구매 가능성  

홍조·심한 염증·통증·진물·지속적 악화는 제품 추천보다 전문가 상담 분기를 우선한다.

---

## 7. API 정책

공식 API는 필수 조건이 아니다.  
다음 경우에만 선택적으로 사용한다.

- 가격·재고 자동 갱신  
- 브랜드 공식 연동  
- 판매처 피드  
- 대량 변경 감지  
- 비용 대비 효과가 충분한 경우  

초기 한국 MVP는 검색 우선으로 실제 판매 제품을 찾고, 검증된 제품만 등록한다.

---

## 8. 금지 사항

- 가짜 제품·가격·재고·링크 생성  
- 근거 없는 효능 설명 생성  
- 검증 전 핵심 추천 포함  
- 등록량 우선 (검증 정확도를 우선한다)

---

## 9. 향후 개발 우선순위

1. 실제 제품 검색 계층  
2. 판매 상태 검증  
3. 전성분 수집  
4. 성분 표준화  
5. 논문 근거 연결  
6. 중복 검사  
7. 관리자 승인  
8. Supabase 등록  
9. 정기 재검증
