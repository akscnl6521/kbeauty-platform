# 카테고리 공통 영상 확보 — 방법과 2026-07-27 결과

MASTER_PLAN §36.2 "카테고리 공통 사용법" / §36.3 "영상 출처와 권리" 대응.
제품명이 붙지 않는 공통 영상만 대상으로 한다. 제품 전용 영상은 별도 트랙.

## 1. 출처를 어떻게 "공식"이라고 판단하는가

검색 결과는 근거가 되지 못한다. 이번 조사에서 검색이 "아모레퍼시픽 공식 채널",
"COSRX 공식"이라고 소개한 영상 6건을 oEmbed로 확인한 결과 **6건 전부 개인
유튜버 채널**이었다. (예: `Q9AdsOlMgdo` → 아는닥터 이원장, `5dneYGhaCpQ` →
Corallista, `nuteDEh6S7A` → Beauty Barn India)

그래서 증거 사슬을 다음과 같이 고정했다.

```
브랜드 자사 웹사이트  →  거기에 링크된 공식 채널 ID  →  그 채널의 RSS 피드  →  oEmbed
```

- **브랜드 자사 사이트**가 링크한 채널만 공식으로 인정한다. 브랜드가 직접
  게시한 링크이므로 제3자가 위조할 수 없다.
- 영상 목록은 **채널 RSS 피드**에서만 가져온다. 검색으로 영상을 찾지 않는다.
  피드는 채널 ID로 YouTube가 서빙하므로 업로더가 바뀔 수 없다.
- **oEmbed**가 iframe을 반환하면 그 영상은 살아있고 업로더가 임베드를
  허용한 것이다. 이것이 우리가 기록하는 권리의 근거 전부다.

관련 스크립트:

| 명령 | 하는 일 |
|---|---|
| `npm run media:discover-channels` | 브랜드 자사 사이트에서 공식 채널 ID 추출 |
| `npm run media:collect-category-videos` | 공식 채널 RSS + oEmbed 검증 + 분류 |
| `npm run media:ingest-category-videos` | 통과분만 Staging에 `needs_review`로 적재 |
| `npm run test:media-category-registry` | 분류 로직 + 레지스트리 형식 검증 |

## 2. 권리를 어떻게 기록하는가

| 항목 | 값 | 근거 |
|---|---|---|
| `rights_status` | `embed_only` | YouTube 표준 임베드 약관 |
| `allows_embed` | oEmbed가 iframe 반환 시 true | 업로더가 임베드 허용 |
| `allows_copy` / `allows_download` | **항상 false** | §36.3 무단 복제 금지 |
| `storage_url` | **항상 null** | 외부 영상은 링크·임베드만. DB CHECK로 강제 |
| `rights_end_at` | 확인일 + 1년 | 아래 설명 |
| `review_due_at` | 확인일 + 7일 | §41 영상 URL 정상 여부 1~7일 |
| `evidence_url` | 채널 링크가 있던 브랜드 사이트 | 공식성의 근거 |

**만료일에 대해**: YouTube 표준 임베드 약관에는 계약상 만료일이 없다. 그렇다고
`rights_end_at`을 비워두면 "영원히 재확인 안 함"이 되어 §41에 어긋난다. 그래서
확인일 기준 **1년의 자체 재확인 기한**을 찍는다. 갱신하지 않으면 만료되어
자동으로 공개 대상에서 빠진다(fail-closed). 계약 만료일이 아니라는 사실은
`media_rights.evidence_note`에 함께 저장한다.

## 3. 2026-07-27 실행 결과

```
공식 채널 (브랜드 사이트 근거 확보)      13개
스캔한 공식 영상                        195건
oEmbed 실패 / 임베드 불가                 0건
공식 채널 업로드로 검증됨               195건 (100%)
─────────────────────────────────────────────
카테고리 공통으로 분류                     0건
제품 전용으로 분류                       195건
```

**카테고리 공통 영상 0건.** 확보 실패다. 원인은 권리나 도구가 아니라 공급이다.

브랜드 공식 채널은 자사 제품을 파는 채널이므로 최근 업로드가 전부 제품
마케팅이었다. 분류기가 감지한 마케팅 신호:

| 신호 | 건수 |
|---|---|
| 제품명 언급 | 75 |
| 신제품 출시 | 31 |
| 한정·에디션·콜라보 | 9 |
| 효과 검증·후기 | 8 |
| 프로모션·세일 | 6 |
| 순위 주장 | 4 |
| 구매 유도 | 1 |

교육형 신호(`바르는 순서`, `사용법`, `세안법`, `아침/저녁 루틴`, `적정량`)는
**195건 중 0건**에서도 감지되지 않았다.

분류기가 과하게 걸러낸 것은 아니다. `npm run test:media-category-registry`는
`"스킨케어 바르는 순서 완전정복"`, `"아침 루틴 바르는 순서"`, `"올바른 이중
세안법"`, `"세럼 바르는 법과 적정량"` 같은 제목을 `category_common`으로 정확히
분류하는지 검증한다. 감지 대상이 실제로 없었다는 뜻이다.

### 조사 범위의 한계

- 채널 RSS는 **최신 15건**만 제공한다. 과거 교육형 영상이 있어도 안 보인다.
  전체 목록을 보려면 YouTube Data API 키가 필요하다(현재 없음).
- 자사 사이트에 YouTube 링크가 없어 검증하지 못한 브랜드 9곳:
  Anua, Beauty of Joseon, Laneige, Sulwhasoo, 넘버즈인, 에스쁘아,
  올리브영(403), LG생활건강(연결 실패), 에뛰드(404).

## 4. 다음에 할 수 있는 것

1. **플랫폼 자체 제작** (§36.3이 명시적으로 허용) — 제품명 없는 공통 영상은
   본래 우리가 만드는 것이 맞다. `rights_status='owned'`, `allows_copy=true`로
   저장 가능한 유일한 경로다. 코드가 아니라 제작이 필요하다.
2. **YouTube Data API 키 확보** — 채널 전체 영상 목록을 훑어 과거 교육형
   콘텐츠를 찾는다. 최신 15건 제한이 풀린다.
3. **브랜드에 직접 사용 허가 요청** — `rights_status='brand_permission'`,
   `evidence_url`에 허가 메일/문서를 남긴다.
4. **공식 판매처 승인 영상** — 올리브영 등 판매처 채널은 이번에 403으로
   접근하지 못했다. 별도 경로 필요.

어느 쪽이든 이번 트랙에서 만든 스키마·게이트·검수 화면은 그대로 쓴다.
막힌 것은 콘텐츠 공급뿐이다.
