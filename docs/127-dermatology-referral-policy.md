# 127 — Dermatology Referral Policy

최종 갱신: 2026-07-13

## 표현

“진단”이 아니라 **“전문가 상담을 권장합니다”**.

## 레벨

| level | 의미 |
|-------|------|
| none | 뚜렷한 추가 신호 없음 |
| consider_soon | 경과 관찰·상담 고려 |
| seek_promptly | 빠른 상담 권고 |
| seek_emergency_care | 가까운 의료기관/응급 안내 |

## 즉시·빠른 권고 후보

심한 붓기 · 강한 따가움/가려움 · 붉음+트러블 동시 고점수 · 중단 후에도 악화 · 2~4주 미호전

## 금지

특정 병원 광고 · 유료 추천 자동 노출 · 질환명 확정
