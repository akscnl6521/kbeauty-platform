# AI 생성 사용 영상 시범 — 검수 기준 (사전 확정)

**작성 시점: 영상 제작 전.** 결과를 보고 기준을 조정하면 채점이 무의미해지므로
먼저 확정한다. 이 문서를 고치지 않고 채점한다.

---

## 1. 대상 제품

| | |
|---|---|
| 제품 | **넘버즈인 2번 로즈 PDRN 콜라겐 플럼핑 세럼 30ml** (`products.id = 54`) |
| 가이드 | `product_usage_guides` · locale `ko` · `needs_review` |
| 출처 | numbuzin.com 공식몰 (브랜드 자사) |

선정 이유: 도포량이 **숫자로** 적혀 있어 영상과 대조 가능한 유일한 스킨케어
세럼이다. (다른 후보 Laneige 스무디 메이크업 세럼은 도포량이 «소량»이라 검증
불가능하고, 메이크업 제품이라 대상에서 제외.)

### 채점 기준이 되는 원문 (verbatim)

> 2~3회 펌핑하여 얼굴 전체에 펴 바른 후, 가볍게 두드려 흡수시켜 줍니다.

| 항목 | 원문이 말하는 것 |
|---|---|
| 도포량 | **2~3회 펌핑** |
| 부위 | **얼굴 전체** |
| 동작 순서 | ① 펌핑 → ② 얼굴 전체에 펴 바르기 → ③ 가볍게 두드려 흡수 |
| 루틴 내 순서 | **원문에 없음** |
| 아침/저녁 | **원문에 없음** |

> 원문에 없는 항목은 **채점하지 않는다.** 영상이 «세안 후»를 묘사하더라도
> 근거가 없으므로 가점도 감점도 하지 않되, 근거 없는 단정으로 보이면 C-4에서
> 다룬다.

## 2. 검수 기준

**모든 항목이 통과해야 통과다.** 하나라도 실패하면 전체 실패로 기록하고,
재생성 없이 원인을 보고한다.

### C-1. 도포량이 가이드 텍스트와 일치하는가

| 판정 | 조건 |
|---|---|
| 통과 | 펌핑 횟수가 **2회 또는 3회**로 셀 수 있게 보이고, 토출량이 그 횟수에 상응 |
| 실패 | 횟수가 1회 이하 또는 4회 이상 / 셀 수 없음 / 펌프가 아닌 방식(스포이드·튜브 등)으로 묘사 |

세럼 용기가 펌프형으로 묘사되어야 한다. 30ml 세럼 2~3펌프는 대략 얼굴 전체
1회분이며, 화면상 토출량이 이를 크게 벗어나면(예: 손바닥을 채울 정도) 실패.

### C-2. 바르는 방향·순서가 일반적으로 알려진 방향과 맞는가

| 판정 | 조건 |
|---|---|
| 통과 | ① 안쪽→바깥쪽, ② 아래→위 방향이 지켜지고, ③ 원문 동작 순서(펴 바른 후 두드림)가 그 순서대로 나타남 |
| 실패 | 위→아래로 쓸어내림 / 바깥→안쪽 / 두드림이 펴 바르기보다 먼저 나옴 / 문지르듯 강하게 비빔 |

«안에서 밖으로, 아래에서 위로»는 피부 처짐 방향을 거스르는 통용 지침이다.
세럼은 문지르지 않고 펴 바른 뒤 두드려 흡수시키는 것이 원문 지시다.

### C-3. 손 모양·동작이 왜곡되지 않았는가

| 판정 | 조건 |
|---|---|
| 통과 | 손가락 **5개**, 관절 방향 정상, 프레임 간 손가락 개수·길이 변화 없음, 제품 용기가 손에서 순간이동하지 않음 |
| 실패 | 손가락 6개 이상/4개 이하, 꺾인 관절, 프레임 간 형태 변형(morphing), 용기·손의 물리적 모순 |

생성 영상의 가장 흔한 실패 지점이므로 **프레임 단위로 확인**한다. 한 프레임이라도
해당하면 실패.

### C-4. §14(화장품 관리 한계)를 넘거나 효과를 과장하지 않는가

| 판정 | 조건 |
|---|---|
| 통과 | 도포 동작만 묘사. 피부 상태 변화가 화면에 나타나지 않음 |
| 실패 | 전후 비교 암시 / 도포 중 피부가 밝아지거나 주름·모공이 사라짐 / 의학적 효과를 연상시키는 자막·시각효과 / 실제와 다른 제형 묘사 |

**«바르는 동작»만 담는다.** 바르는 사이 피부가 좋아지는 묘사는 그 자체로
과장이며, AI 생성이라는 사실과 결합하면 실제 사용 결과로 오인될 위험이 크다.

### C-5. §36.3 «AI 생성 콘텐츠» 표시 (필수)

| 판정 | 조건 |
|---|---|
| 통과 | 영상 **화면 안에** 한국어 «AI 생성 콘텐츠» 표기가 재생 내내 판독 가능하게 노출 |
| 실패 | 표기 없음 / 일부 구간에만 노출 / 판독 불가 크기 / 메타데이터에만 존재 |

메타데이터의 `disclosure` 컬럼은 별개다. §36.3은 **콘텐츠 자체**에 표시를
요구하므로 영상에 구워 넣어야 한다.

## 3. 통과 시 저장 방식

통과해도 **자동 공개하지 않는다.**

```
media_assets
  asset_type            = 'product_usage'
  scope                 = 'product_specific'
  media_type            = 'video'
  source_type           = 'platform_original'   -- 자체 제작. storage_url 허용되는 유일한 계열
  is_ai_generated       = true
  content_relationship  = 'ai_generated'        -- 스키마 CHECK가 강제
  disclosure            = 'AI 생성 콘텐츠입니다. ...'
  verification_status   = 'needs_review'        -- 사람 승인 전까지 공개 불가
  shows_product_name    = (영상에 제품명이 보이면 true)
product_videos          -- product_id = 54 연결
media_rights            -- rights_status='owned', 자체 제작이므로 복제·보관 허용
```

스키마가 이미 강제하는 것: `is_ai_generated=true`인데
`content_relationship`이 `ai_generated`가 아니면 **INSERT 자체가 거부**된다
(`media_assets_ai_disclosure_chk`).

## 4. 채점 방법

영상 자체는 디코딩할 수 없으므로, 채점하려면 **프레임을 이미지로** 받아야 한다.
최소 요구: 시작·중간·끝 + 손이 화면에 크게 잡히는 구간 등 **6~10 프레임**.
C-3(손 왜곡)은 프레임 단위 확인이 필수라 정지 이미지 없이는 판정 불가다.

---

## 5. 이 방향을 재검토할 때 볼 지표

시범 1건의 통과/실패보다, **어느 기준에서 실패했는지**가 대량 제작 여부를
가른다.

| 실패 지점 | 시사점 |
|---|---|
| C-3(손 왜곡) | 생성 모델의 한계. 프롬프트로 개선 여지 있으나 검수 비용이 커진다 |
| C-1·C-2 | 프롬프트에 가이드 텍스트를 넣으면 개선 가능 |
| **C-4** | **가장 위험.** 모델이 «좋아 보이게» 만들려는 경향이라 구조적으로 재발한다 |
| C-5 | 후처리로 해결 가능(오버레이) |

C-4가 반복 실패하면 이 방향 자체를 접는 근거가 된다 — 과장 없는 영상을 만들기
위해 매건 사람이 프레임을 검수해야 한다면, 자체 촬영보다 비싸다.
