## 테이블: product_offers (신규)

제품 본체와 국가별 판매 Offer를 분리한다.  
마이그레이션: `supabase/migrations/20260712000000_create_product_offers.sql`

| 컬럼 | 용도 |
|------|------|
| `id` | Offer 식별자 |
| `product_id` | products.id FK |
| `retailer_name` | 판매처명 |
| `retailer_country` | KR / US / JP / GLOBAL |
| `ships_to_countries` | 배송 가능 국가 배열 |
| `purchase_url` | 구매 URL |
| `price`, `currency` | Offer 가격 (KRW/USD/JPY) |
| `stock_status` | in_stock / out_of_stock / unknown |
| `verification_status` | verified / unverified / invalid / unavailable |
| `is_official`, `verified_at`, `last_checked_at` | 공식·검증 메타 |
| `rating`, `review_count`, `source`, `last_review_sync_at` | 향후 리뷰 (점수 미반영) |

핵심 추천 후보 조건: 선택 배송 국가에 `verified` offer + 가격·통화 + 허용 재고 + 유효 URL.

데이터 목표: KR/US/JP 각 100+ offer, 주요 성분별 제품 수(판테놀·세라마이드 등)는 `CATALOG_DATA_GOALS` 참고.
