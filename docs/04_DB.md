# 04. DB — 데이터베이스

## 개요

데이터 저장소는 **Supabase (PostgreSQL)** 를 사용한다.  
앱은 anon 키로 브라우저에서 직접 조회하며, 현재 확인된 주요 테이블은 `products`, `ingredients`이다.

## 연결 정보

- 클라이언트: `src/lib/supabase.ts`
- 환경변수:
  - `NEXT_PUBLIC_SUPABASE_URL`
  - `NEXT_PUBLIC_SUPABASE_ANON_KEY`
