# 05. AI — AI 통합

## 개요

현재 AI 기능은 **피부 분석**에 집중되어 있다.  
`/analyze` 페이지에서 Anthropic Claude를 호출해 피부 타입·고민·추천 성분·다국어 요약을 생성한다.

## 현재 구현

| 항목 | 내용 |
|------|------|
| 위치 | `src/app/analyze/page.tsx` |
| 제공자 | Anthropic |
| 모델 | `claude-sonnet-4-20250514` |
| 호출 방식 | 브라우저 → `https://api.anthropic.com/v1/messages` |
| 키 | `NEXT_PUBLIC_ANTHROPIC_API_KEY` |
| 입력 | 사진 업로드 또는 수동 피부 정보 |
| 출력 | 피부 타입, 고민, 추천 성분, ko/en/ja 요약, 루틴 팁 |
| 저장 | `localStorage.skinAnalysisResult` |

## 제품 추천과의 연결

현재 연결은 약하다.

```text
AI 분석 결과
  → tone, 첫 concern 등을 query로 전달
  → /results?tone=...&concern=...&ai=1
  → 규칙 기반 필터 (AI 점수 재랭킹 없음)
```

- `ai=1`은 UI 배지 표시 수준
- 추천 성분 전체·다중 고민·루틴 팁은 제품 랭킹에 미반영

## 보안 이슈 (중요)

1. API 키가 `NEXT_PUBLIC_` 으로 노출됨
2. 브라우저에서 Anthropic을 직접 호출함
3. 서버 rate limit / 요청 검증이 없음

### 권장 구조

```text
브라우저 → POST /api/analyze → 서버(ANTHROPIC_API_KEY) → 응답 검증 → 클라이언트
```

1. **제품 재랭킹**: 고민·톤·성분·가격 스코어링

3. **추천 이유 생성**: `recommendation_reason_*` 보완
4. **루틴 최적화**: 사용 순서·성분 충돌 분석
5. **의미 검색**: embedding + pgvector
6. **다국어 초안**: 누락 번역 생성 (검수 워크플로 필요)
