# 아침·저녁 루틴 영상 — 범위 확정 후 검토 (2026-07-27)

원본 프롬프트: `kbeauty-platform/아침저녁 세안후 바르는 화장품순서.txt`

## 0. 확정된 범위

| 다룬다 | 다루지 않는다 |
|---|---|
| 세안법 (아침/저녁) | **용량 (mL·방울 수·펌핑 횟수 등 일체)** |
| 스킨케어 순서 | |
| 바르는 방법 = **동작** | |

용량을 빼면 앞서 정한 시범 기준 **C-1(도포량 일치)은 이 영상에 적용하지 않는다.**
대신 동작의 정확성을 §36.5 가이드 데이터와 대조한다(§2).

---

## 1. 순서 — 우리 실데이터와 충돌 없음

검증된 가이드 22건 중 순서 근거를 가진 6건과 전부 일치한다.

| 우리 DB 근거 | 프롬프트 | 일치 |
|---|---|---|
| 선크림 → `마지막 단계` | sunscreen이 스킨케어 마지막 | ✓ |
| 토너 3건 → `세안 후` | cleanser → toner | ✓ |
| 메이크업 세럼 → `스킨케어 마무리 후` | 스킨케어 후 makeup | ✓ |
| 시트마스크 → `세안 후` | — | **슬롯 없음** |

**근거의 한계**: 직접 검증된 지점은 «세안 후», «스킨케어 마무리 후»,
«마지막 단계» 세 곳뿐이다. 에센스↔세럼↔아이크림 사이의 상대 순서는 우리
데이터에 근거가 없다. 그래서 다음 두 가지를 반영한다.

- **"the correct order" → "일반적으로 권장되는 순서"** 로 완화
- **시트마스크 슬롯 추가** — «세안 후 / 토너 다음» 위치. 현재 프롬프트에는
  sleeping mask(마지막)만 있어 시트마스크 보유 제품 3건이 잘못 배치된다

## 2. 동작 대조 — **부분 불일치. 이게 이번 검토의 핵심이다**

검증된 가이드 22건의 `method_steps`에서 실제로 근거가 있는 동작:

| 동작 | 근거 | 등장 카테고리 |
|---|---|---|
| **펴 바르기** | **10건** | serum · sunscreen · ampoule · moisturizer · cleanser · cream |
| **흡수시키기** | **10건** | serum · mask · ampoule · toner · moisturizer |
| **두드리기** | **9건** | serum · mask · ampoule · moisturizer · cream |
| 마사지 | 5건 | shampoo · 클렌징오일 |
| 헹구기 | 4건 | shampoo · 클렌징오일 |
| 닦아내기 | 3건 | toner (화장솜) |
| 거품내기 | 3건 | shampoo · cleanser |
| 원 그리기 | 2건 | 메이크업세럼(모공 굴리기) · 클렌징 롤링 |
| 레이어링 | 2건 | serum · lip care |
| **문지르기** | **1건** | **cleanser 전용** |

### 지시하신 동작 3종에 대한 판정

| 동작 | 판정 | 근거 |
|---|---|---|
| **두드리기** | **✅ 사용 가능** | 9건. 바르고 나서 흡수시키는 마무리 동작으로 확립돼 있다 |
| **문지르기** | **⚠️ 세안 단계에서만** | 단 1건이고 그 문장은 `거품을 충분히 낸 후 … 마사지하듯 가볍게 문질러 미온수로 헹구어 냅니다` — **세안 전용**이다. 세럼·크림 같은 leave-on 단계에서 문지르는 근거는 **0건** |
| **원 그리기** | **⚠️ 일반화 불가** | 2건뿐이고 둘 다 특수 케이스(모공 부위 굴리기 / 클렌징 롤링). 일반 스킨케어 동작으로 보여주면 근거를 넘어선다 |

**핵심**: 우리 데이터에서 leave-on 제품(토너·세럼·크림)의 표준 동작은
**«펴 바른다 → 가볍게 두드려 흡수시킨다»** 이지 «문지른다»가 아니다.
영상에서 세럼을 문지르는 장면을 넣으면 우리가 보유한 검증 텍스트와 어긋난다.

### 방향 — 데이터에 있는 것과 없는 것

근거 있음:
- **`피부결을 따라`** — 5건 (ampoule · toner · serum)
- **`안쪽에서 바깥쪽으로`** — 3건 (toner, 화장솜 사용 시)
- **`눈 주위를 피해`** — 2건 (toner · 마스크팩)

근거 **없음**:
- **`아래에서 위로`** — 22건 중 **0건**. 널리 알려진 통념이지만 우리 검증
  데이터에는 없다. 영상 채점 기준에서 이를 «데이터 근거»로 쓰면 안 된다
  (일반 통념으로는 쓸 수 있으나 그렇게 표시해야 한다)

→ 영상의 방향 묘사는 **«피부결을 따라, 안쪽에서 바깥쪽으로, 눈가는 피해서»**
를 기준으로 한다. 이 셋은 우리 데이터에 실재한다.

## 3. §14 보완 — 용량과 무관하게 그대로 필요

§14 첫 문장: *"모든 피부 고민을 제품으로 해결할 수 있는 것처럼 표현하지 않는다."*

원본 프롬프트는 `Avoid making guaranteed medical claims`로 **표현 수위**는
통제하지만, §14가 요구하는 **전문가 연결**이 통째로 빠져 있다.

| 프롬프트 내용 | §14 규정 | 누락 |
|---|---|---|
| Acne treatment / Acne-prone skin | 반복되는 심한 염증성 여드름 = 화장품만으로 부족 | 피부과 안내 없음 |
| Brightening products | 오래 지속되는 심한 색소 변화 = 화장품만으로 부족 | 동일 |
| 레티놀 · AHA/BHA 권장 | 통증·진물·발진 = 의료기관 확인 우선 | **이상 반응 시 중단 안내 없음** |
| — | §36.2 «부작용·자극 발생 시 중단 가이드» | 항목 자체 없음 |

**영상에 반드시 포함할 문구 2가지**

1. 이상 반응(붉어짐·따가움·부어오름) 시 **즉시 사용 중단**
2. 심한 염증성 여드름 · 오래된 색소 변화 · 통증/진물/발진은 **피부과 확인이 먼저**

15~30초 영상에서 이 두 문장은 자막으로 처리하되, 순서 설명과 같은 비중으로
읽히게 한다. 짧은 영상은 «이 순서 = 해결»이라는 인상이 글보다 강하게 남는다.

## 4. 얼굴 일치 검증 — **여전히 선행 조건. 순서 유지**

영상 제작은 이 로직이 완성된 뒤에 넘어간다.

| 있는 것 | 없는 것 |
|---|---|
| 레퍼런스 9장 등록 (`kbm-main-model`, 비공개 버킷) | **얼굴 임베딩·유사도 비교 코드 0줄** |
| 정체성 고정 프롬프트 원문 보존 | 합격 판정 임계값 |
| 정지 이미지 육안 대조 | **영상 프레임 디코딩 수단 (ffmpeg 없음)** |

추가 난점: 레퍼런스 9장은 전부 **회색 배경 · 상반신 · 업두**다. 루틴 영상은
욕실 화장대 · 손 동작 클로즈업이라 구도·조명이 전부 다르다. 이 간극을 넘는
동일인 판정은 정량 기준 없이는 주관적이다.
