# 01. Vision — K-Beauty Match

## 개요

K-Beauty Match는 글로벌 사용자를 위한 AI 기반 스킨케어 추천 플랫폼이다.  
피부 톤·고민·예산·성분 정보를 바탕으로 개인화된 K-뷰티 제품을 발견할 수 있도록 한다.

## 제품 미션

- 전 세계 사용자가 자신의 피부에 맞는 한국 스킨케어를 쉽게 찾게 한다.
- 설문·얼굴 탐색·AI 분석을 통해 추천의 진입 장벽을 낮춘다.
- 성분 정보와 추천 이유를 제공해 신뢰할 수 있는 선택을 돕는다.

## 타깃 사용자

- K-뷰티에 관심 있는 해외 사용자 (영어·일본어 중심)
- 피부 고민에 맞는 제품을 찾고 싶은 국내 사용자
- 성분·루틴을 기준으로 스킨케어를 구성하고 싶은 사용자

## 핵심 가치 제안

1. **개인화**: 피부 톤, 고민, 예산 기반 필터링
2. **AI 분석**: 사진/입력 기반 피부 분석 및 성분 힌트
3. **성분 신뢰**: 성분 상세·논문 정보 제공
4. **다국어**: 영어 / 일본어 / 한국어 지원
