# Core Journey Gap Closure Sprint

최종 갱신: 2026-07-19
기준 문서: K-Beauty Match Master Plan v4.1
작업 브랜치: `docs/master-plan-v4.1-20260718`

## 1. 목적

피부 분석, 안전 분기, 추천, 결과 저장, 지속 관리, 제품 데이터 자동화를 하나의 검증 가능한 흐름으로 연결한다.

## 2. 완료된 사용자 여정

```text
문진 시작
→ 부위·증상·심각도·발생 기간 입력
→ 위험 신호 확인
→ 화장품 관리 가능 범위 판정
→ 추천 성분·주의 성분
→ 안전 정책에 따른 제품 노출
→ 결과 저장
→ Day 3·7·15·30 체크인 생성
→ /my에서 현재 상태·다음 행동 확인
→ 악화 시 전문가 상담 분기
```

## 3. 완료된 제품 자동화 흐름

```text
한국 제품 후보 생성
→ 공식 브랜드 페이지 확인
→ robots 정책 확인
→ 공식 이름·이미지·전성분·가격·재고 추출
→ 정규화
→ 기존 제품과 중복·변경 비교
→ 신규 후보 / 기존 후보 갱신 / 변경 없음 / 수동 검수 / 거부 분류
→ Staging 동기화 작업 계획 생성
→ 공개 전 사람 검수
```

## 4. 안전 규칙

- 공식 출처가 확인되지 않은 값은 생성하지 않는다.
- 전성분·가격·재고·이미지가 없으면 누락 상태로 유지한다.
- placeholder와 발견용 가상 후보는 자동 거부한다.
- robots 차단 또는 공식 매칭 실패는 수동 검수로 보낸다.
- 기존 정보와 변경이 없으면 DB 쓰기를 생략한다.
- 자동 수집 결과는 Staging 후보 또는 검수 대상으로만 처리한다.
- Production 공개·검증 상태를 자동 승격하지 않는다.
- `urgent_check`에서는 제품과 구매 노출을 차단한다.
- `expert_first`에서는 보조 관리 범위만 허용한다.

## 5. 자동 갱신 주기

- 처리 실패: 1일 후 재시도
- 공식 출처 미확인 또는 검수 필요: 3일 후 재확인
- 이미지·전성분·판매처 누락: 7일 후 재확인
- 정보 완료 제품: 30일 주기 점검
- 중복 후보: 90일 주기 감시
